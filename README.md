# 🐱 바탕화면 고양이

바탕화면 배경 속에 사는 동글동글 뚱냥이예요.
대부분 자고, 가끔 깨서 어슬렁거리다가 바탕화면 아이콘을 앞발로 툭툭 밀어요.
고양이에게 Claude 질문을 할 수도 있어요.

- **종류**: 삼색냥 · 치즈냥 · 검은냥 · 흰냥
- **지원**: Windows 10 / 11 (64비트)
- **라이선스**: 개인이 쓰는 건 무료예요 → [LICENSE](LICENSE) · [면책 조항](DISCLAIMER.md) · [오픈소스 고지](THIRD_PARTY_NOTICES.md)

## 1. 시작하기

### 내려받기

**[Releases](../../releases/latest)**에서 받아요.

| 파일 | 쓰는 법 |
|---|---|
| `DesktopCat-Setup-1.2.0.exe` | **설치 프로그램(추천)**. 마법사를 따라 설치하면 시작 메뉴에 등록되고, 설정 > 프로그램 제거에서 지울 수 있어요. 관리자 권한은 필요 없어요 |
| `DesktopCat-Portable-1.2.0.exe` | 받아서 바로 더블클릭. 파일 하나라 간편해요 |
| `DesktopCat-1.2.0-win-x64.zip` | 압축을 풀고 `DesktopCat\DesktopCat.exe` 실행. 켜지는 속도가 더 빨라요 |
| `*.sha256` | 받은 파일이 맞는지 확인하는 값 |

받은 파일이 맞는지 확인하려면 PowerShell에서:

```powershell
Get-FileHash .\DesktopCat-Portable-1.2.0.exe -Algorithm SHA256
```

나온 값이 `.sha256` 파일의 값과 같아야 해요.

> **실행이 막힐 수 있어요.** 이 프로그램은 코드 서명이 없어요.
>
> | 증상 | 해결 |
> |---|---|
> | **"Windows의 PC 보호"** 창이 떠요 (SmartScreen) | **추가 정보 → 실행** |
> | **"응용 프로그램 제어 정책이 이 파일을 차단했어요"** (Smart App Control이 켜진 PC) | 이 PC에서는 실행할 수 없어요 |
>
> Smart App Control은 서명 없는 프로그램을 무조건 막는 Windows 11 보안 기능이에요.
> 끄면 실행되지만, **한 번 끄면 Windows를 초기화하기 전에는 다시 켤 수 없어요.** 보안 수준이 낮아지니 권하지 않아요.

## 3. 질문하기

1. 고양이를 **2번** 누르거나 `Ctrl+Alt+K`를 눌러요.
2. 머리 위 말풍선에 질문을 쓰고 `Enter`를 눌러요. (`Shift+Enter`는 줄바꿈)
3. 답이 말풍선에 이어서 나와요.
4. 답 **아래 칸**에 바로 이어서 물어볼 수 있어요. (고양이를 2번 눌러 새 질문을 열어도 돼요)

| 상황 | 말풍선 |
|---|---|
| 질문 칸을 열고 **10초** 동안 아무것도 안 쓰면 (설정에서 바꿔요) | 저절로 닫혀요 |
| 답이 끝나고 **20초**가 지나면 (이어서 쓰는 중에는 안 접혀요) | 작은 `…` 말풍선으로 접혀요. 누르면 다시 펼쳐져요 |
| `Esc` 또는 `×` | 닫기 (답을 받는 중이면 취소) |

최근 대화 6개를 10분 동안 기억해서 이어서 물어볼 수 있어요. 답 아래의 **새 대화**를 누르면 기억을 지우고 처음부터 시작해요.

질문은 **2,000자**까지 넣을 수 있어요. 오류가 나면 이유를 알려 줘요 (로그인 필요, 구독 한도, 결제·크레딧, 서버 문제, 연결 문제, 응답 없음 등).

### 질문 방식 고르기 (우클릭 → 설정 → 질문하기)

| 방식 | 필요한 것 |
|---|---|
| **Claude Code 구독** (기본) | 이 PC의 Claude Code(`claude.exe`)에 한 번 로그인<br>→ 설정 → **Claude Code 로그인 창 열기**<br>못 찾으면 설정 → claude.exe → **찾아보기…** 로 직접 골라요 |
| **Anthropic API 키** | 설정 창에 API 키 입력 |

## 4. 고양이가 하는 일

| 행동 | 설명 |
|---|---|
| 😴 낮잠 | 식빵 자세로 있다가 동그랗게 말고 1~5분 자요. 깨면 기지개 → 하품 → 그루밍 |
| 🐾 아이콘 장난 | 아이콘 옆에 앉아 빤히 보다가 앞발로 툭툭. 가끔은 멀리 쳐 버려요. **배경화면 속에서 돌아다닐 때만, 보이는 아이콘만** 건드려요 |
| 🛏️ 아이콘 위에서 자기 | 가끔 아이콘 위에 올라가서 자요 |
| 💨 우다다 | 기운이 넘치면 바탕화면을 뛰어다녀요 |
| 🙀 도망가기 | 깨어 있을 때 마우스가 **확** 다가오면 깜짝 놀라 달아나요. 자는 중에는 안 도망가요(설정에서 끌 수 있어요) |
| 🎯 사냥 | 바탕화면에서 마우스를 움직이면 가끔 엎드려 노리다가 덮쳐요 |

많이 놀면 졸려서 자고, 자고 나면 다시 놀아요.

### 바탕화면이 가려지면?

| 상황 | 고양이 |
|---|---|
| 바탕화면이 보일 때 | 아이콘 뒤 **배경화면 속**에서 지내요 |
| 창이 바탕화면을 가릴 때 | **화면 맨 아래**(작업 표시줄 위)로 내려와 걷거나 자요. 이때는 아이콘 장난을 쉬어요 |
| 발표·영상 같은 **전체 화면**일 때 | 방해하지 않게 숨어요 |

## 5-1. 동물 팩 설치

고양이 말고도 다른 동물을 **동물 팩**으로 설치해서 함께 지낼 수 있어요.

1. 설정 → **동물 팩 → ＋ zip 설치…**(또는 폴더 설치)에서 팩 파일을 골라요.
2. 이름·만든 사람·품종을 확인하고 **예**를 누르면 설치돼요.
3. 설정 맨 위 **내 동물**에서 동물을 골라요. 동물마다 이름·크기·품종·움직임이 따로 저장돼요.

**공식 동물 팩**은 Releases의 `DesktopCat-Pack-<이름>-<버전>.zip`이에요.

| 팩 | 품종 | 성격 |
|---|---|---|
| **강아지** | 시바견 · 리트리버 · 웰시코기 · 푸들 · 달마시안 | 활발하고 마우스를 졸졸 따라와요. 마우스가 확 다가오면 꼬리를 흔들며 반겨요 |
| **토끼** | 흰토끼 · 회색 토끼 · 롭이어(귀가 처진 토끼) | 깡충깡충 뛰어다녀요. 겁이 많아서 마우스가 확 다가오면 얼어붙었다가 도망가요 |
| **햄스터** | 골든 햄스터 · 정글리안 · 흰 햄스터 | 작고 동글동글해요. **밤(저녁~새벽)에 활발**하고 낮에는 많이 자요. 마우스가 확 다가오면 얼어붙었다가 짧게 도망가요 |

동물 팩은 **그림과 행동 성격 데이터(.json)만** 담고 있어요. 프로그램 코드는 실행하지 않고, 설치할 때 파일 종류·크기·경로를 모두 검사해요(.exe·.js 같은 파일이 든 팩은 받지 않아요). 팩은 `%APPDATA%\desktop-cat\plugins\`에 설치돼요.

🎨 **나만의 동물을 만들고 싶다면** → [동물 팩 만드는 법](동물-팩-만드는-법.md)

## 6. 알아 두면 좋은 것

- **아이콘이 칸에 딱 붙어 움직이면**: 바탕화면 우클릭 → 보기에서
  **아이콘 자동 정렬**과 **아이콘을 그리드에 맞춤**을 꺼 주세요.
- **고양이는 한 마리만**: 이미 켜져 있으면 다시 실행해도 새로 뜨지 않아요.
- **자동 실행 경로**: 배포판을 다른 폴더로 옮겼다면 한 번 실행하면 자동 실행 경로가 새 위치로 고쳐져요.

## 7. 개인정보와 저장 위치

모든 데이터는 이 PC의 `%APPDATA%\desktop-cat\`에만 저장해요.

| 파일 | 내용 |
|---|---|
| `settings.json` | 설정 (종류, 크기, 질문 방식 등) |
| `secrets.bin` | API 키 — Windows DPAPI로 암호화 (이 Windows 계정에서만 풀려요) |
| `icons-backup.json` | 켤 때의 아이콘 자리 |
| `usage\ledger.jsonl` | 질문에 쓴 모델 이름과 토큰 수 (**질문·답 내용은 저장하지 않아요**) |
| `logs\error.log` | 오류가 났을 때의 기록 |

- **사용량 창**은 Claude Code 기록(`~\.claude\projects`)에서 **모델 이름·시각·토큰 수만** 읽어요.
- **구독 방식 질문**은 Claude Code를 **답만 하도록** 실행해요. 도구·MCP·설정 파일·CLAUDE.md·세션 기록을 쓰지 않고, `ANTHROPIC_API_KEY` 환경 변수도 넘기지 않아요.
- **API 키 방식**은 `api.anthropic.com`에만 연결해요.
